TESTING SCENARIOS COVERED
──────────────────────────────────────────────────────────────────────────────

Process-Level Crashes:
  • SIGKILL - Hard crash simulation
  • SIGTERM - Graceful termination
  • SIGABRT - Abnormal exit
  • SIGSEGV - Segmentation fault

Container-Level Crashes:
  • PID 1 kill (SIGKILL)
  • PID 1 abort (SIGABRT)
  • PID 1 term (SIGTERM)
  • Docker stop/restart
  • OOM trigger (optional)

Verification Checks:
  • Process running status
  • Container running status
  • SSL certificate preservation
  • Database integrity
  • Port connectivity (50001-50004)
  • Container uptime tracking
  • Restart count monitoring
